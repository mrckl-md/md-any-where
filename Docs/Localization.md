# 界面本地化与译文审核

修订日期：2026-10-06；译文与历史测试核对日期：2026-10-05。`md any where` 目前提供 47 份离线界面 catalog，每份包含 583 个 Web 与原生字符串。它们对应 [Apple 的 50 项商店本地化](AppStore/Localization.md)：四个英语地区共用 `en.json`，其他项按清单映射。商店语言、应用语言与可销售国家／地区是不同设置，语言文件齐全不表示所有地区已获准销售。

## 译文来源与使用方式

英文和简体中文为维护源；其余界面文案主要由翻译服务生成初稿，再作机器辅助检查与定点修订。翻译服务仅用于开发阶段制作资源，不是应用运行时依赖。catalog 随应用离线打包，切换界面语言本身不需要把正在编辑的文稿交给翻译服务。

**这些译文仍是机器辅助初译，未经每种语言的母语编辑审定。** 键数量、参数正确或布局测试通过，均不能证明每句话自然、术语统一，或满足所有地区的法律表达要求。欢迎母语贡献者按下述范围继续校对；不得用英文整段回退来冒充某语言已翻译。

## 本轮重点语义复核

已检查全部 47 份 catalog 中的远程发送说明，以及关闭文稿时的保存、放弃与取消文案。重点保留：

- `native.agent.transferBody`、`native.agent.mobileTransferBody` 中的接收方 `{0}`、发送范围 `{1}`、向多服务分别发送的说明，以及同意仅对本次请求有效。
- `native.close.*` 中未保存内容会丢失的含义；保存、取消与不保存三个动作不可混淆。
- 隐私说明中的默认停用、每次明确同意、可能发送全文／前序答案、服务商自己的留存与训练政策，以及删除本机内容不等于删除第三方数据。
- API Key 虽持久保存于 Keychain，运行时仍会发往所配置端点或代理；macOS MCP/CLI 的适用范围与本机监听限制。

本轮定点修订 73 个值，没有新增或删除 catalog 键，没有更换占位符。其中包括把孟加拉语、卡纳达语和泰米尔语误译为刑罚的“执行”改为本次请求，修正印地语“不保存”的储蓄歧义、奥里亚语“未保存”的否定与混杂字词、马拉地语应撤销“已不再使用”的 Key，以及繁体中文隐私段落中的简繁混杂。

45 份非英文／非简体中文隐私段落修正了初译中的数据留存主语或否定关系：服务可能保留数据且不立即删除，应用不保证零留存或立即删除。没有为任意自定义代理作“不存储”“不训练”或自动删除的承诺。

这是依据源文案进行的重点审查，不是对 47 × 583 个值的母语认证。下一轮母语审校应优先检查同意框、数据范围、删除／恢复提示与隐私段落，再处理较低风险的术语和行文风格。

## 可重复验证

在仓库根目录运行：

```sh
node scripts/test-localization.cjs
node scripts/test-locale-runtime.cjs
./scripts/test-native-localization.sh
./scripts/test-localized-editor.sh
python3 Docs/AppStore/validate-localizations.py
```

历史版本 `3` 的检查曾通过：47 份 catalog 键集一致、每份 583 条，占位符与 UTF-8 字符有效；50 项商店文案的字段与长度限制通过。JS、原生和商店清单的 50 项代码逐项一致；系统语言别名、偏好优先级、格式化和桥接回传通过。真实 WebKit 覆盖全部 50 项语言切换中的文稿、撤销、工作流和未保存设置保留，以及 9 种代表语言 × 3 种宽度的 27 组布局。

当前构建 `4` 已完成原生本地化回归，模拟器包中 47 份 catalog 和 51 个语言目录已核对，iPhone/iPad 模拟器安装启动成功。50 项语言 WebKit 状态保留与 27 组布局回归也已通过；这些是构建 `4` 的本轮结果，仍不替代物理设备交互或发行包验收。

回归测试包含采用 Agent 工作流建议之后再切换语言，防止隐藏建议节点引用已清空状态而中断刷新。还检查显式脚本标记，如 `zh-Hans-HK`、`en-Latn-GB`、`es-Latn-ES`，避免匹配错误的地区变体。这些检查不代替语义审校、真机交互或最终分发包验证。

修订译文时只更新已确认的字符串值，保留键名、插值参数、品牌、路径及 Markdown／公式／流程图语法。不要重新运行初译解码覆盖已经复核的修订；新增语言或功能后应重新运行上述检查，并复核受影响的界面与提示。
