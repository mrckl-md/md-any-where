md any where 隐私政策与数据使用说明

当前应用版本 1.0.0 · 2026 年 10 月 5 日

本机文稿与草稿

普通编辑、查找、离线预览、公式转换和导出在设备上完成；当前没有广告、遥测上传或开发者运营的文稿服务器。应用访问您选择或主动打开的文稿，不自行扫描其他资料。iPhone/iPad 会在应用私有容器保存当前标签页正文、最近保存内容及文件访问书签，供重启恢复。恢复副本使用系统文件保护，可能进入系统备份；选择 iCloud Drive 等文件提供商时，同步由相应服务及系统设置管理。

设置、密钥与剪贴板

偏好、端点、模型与工作流要求保存在本机。API Key 持久存入系统钥匙串；运行 Agent 时仍会作为认证信息发送给所配置端点或代理。请只使用可信地址。复制会写入系统剪贴板，粘贴会读取剪贴板；相关系统同步由您的系统设置决定。

第三方 Agent

所有 Agent 默认停用。每次远程运行前会列出接收服务/主机与发送范围，只有您明确同意本次发送才继续。请求可能包含任务要求、选区、上下文或全文；并行评审、共识及工作流也可能向多个已选服务发送前序答案。DOCX 排版 Agent 只接收排版要求与设置。内容直接发往配置端点；接收方也会收到认证和网络连接信息，可能关联您的 API 账户并保存日志。数据保留、训练设置和删除方式依实际服务商政策，应用不能承诺所有服务都不存储或立即删除。回环地址服务是否继续联网由其提供者决定。

本机控制台

MCP / 命令行控制台仅适用于 macOS，默认关闭且只监听回环地址。除状态检查外，文稿读取和修改请求仍需您在 md any where 中确认。Agent 宿主可能按自身策略处理获准读取的内容。

撤回与删除

您可拒绝单次发送、停用 Agent，或点击“清除密钥”并保存配置；停用服务不自动删除 Key。关闭移动端标签页会从后续恢复副本移除它，未保存内容先询问是否保存；不会删除已另存的文件或备份。卸载不保证清除钥匙串，请在服务商账户撤销不再使用的 Key。删除本机内容不会删除第三方已收到的数据。

联系与完整说明

完整政策见公开项目 github.com/mrckl-md/md-any-where 的 PRIVACY.md；支持入口为同仓库 Issues，也可发送邮件至 longshenggdgz@163.com。反馈时不要附带真实 Key、私密文稿或未脱敏日志。

操作记录

选择任意记录，将当前文稿回退或前进到该状态。

每个标签页分别保存记录；达到设置中的步数后，最旧记录会自动移除。回退后继续编辑会建立新的历史分支。

公式转换器

选中公式后规范化，并复制到学术编辑软件。

输入公式后在此预览

Word/WPS：先插入公式框（Word 为 ⌥=，输入格式选 LaTeX），再粘贴即可保持可编辑；剪贴板同时提供 MathML、LaTeX 与 SVG，目标软件会选择它支持的最佳格式。

查找与替换

支持精确、忽略大小写、模糊和 Agent 语义查找。

输入内容开始查找

普通和模糊查找完全在本机进行。只有主动点击 Agent 查找或总结全文，当前完整文稿才会发送给已启用的 Agent。

Agent 编辑台

可单独运行一个模型，或组成并行评审 / 共识集群。
